Develop or revise a product design for the user's request. Load the design-product skill and follow it, including the playbook it selects and every principle leaf it names. Run one phase, then stop: Understand, then Shape, then Specify. Start the next phase only when this message approves the previous phase or asks to brainstorm that next phase. Do not run technical design; that is `/technical-design`, and only after Specify is approved or the person asks to brainstorm it. First apply references/discovery-interview.md: missing core context requires an interview in Understand, even for advise or Full. If questions are explicitly forbidden, provide only discovery summary, gaps, and research plan, then stop. If the user says advise, read references/advise-mode.md and recommend inside the open phase only.

Use references/learning-loop.md to connect sources, synthesis, opportunity choice, alternatives, early test planning, and supplied results to decisions. Match artifacts to the research question and declared output level; do not mistake a complete design package for validation or approval.
