# Take on the Hard Work

Simplicity for the user is the result of the product absorbing rules, exceptions, memory, and coordination.

- Leaving out a hard case, a denied path, or an error is not simplicity
- "It has always been done this way" is not a reason to export the organisation's complexity onto the user
- Show the hard case in the journey, and say which part of the product carries it
