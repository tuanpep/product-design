# See the Whole Service

Map the real journey and the context around it, then do only the irreducible core.

- Include place, device, skill, time pressure, other people, and other organisations
- Prefer stopping, reusing, or a non-software change when that meets the outcome
- A screen that completes one step while the journey fails is not a success
- A new product that rebuilds something which already works is not a success either
