# Translationese

Translationese is wording that follows the source language instead of the target language. A native speaker can parse it and still hears that it was translated. Replace the sentence. Do not patch one word.

These pairs are English interface text rewritten from a literal draft. Apply the same test in whatever language the product shows.

| Literal draft | Write this |
| --- | --- |
| Please kindly be informed that your request has been approved successfully. | Request approved. |
| The system has occurred an error. Please try again later. | We could not save this. Try again. |
| Input the colleague name into the below field. | Colleague's name |
| Click the button below to perform the submission of the form. | Send request |
| You are not allowed to do this action. | You can't approve this request. Ask the charge nurse. |
| Empty data | No requests yet. Ask for cover when a shift needs it. |
| Make the confirmation of the deletion? | Delete this request? This can't be undone. |

## What to look for

- **Calques.** A source idiom or compound translated piece by piece: "input the name into the below field", "perform the submission".
- **Source grammar.** Articles, plurals, classifiers, or word order copied from the other language.
- **Padding.** "Please kindly be informed", "successfully", "the system". They add no fact.
- **Noun stacks.** "request approval confirmation action". Say who does what.
- **False friends.** A word that looks like the right translation and means something else. Check the glossary before keeping it.

## What to keep

Keep a term when the audience already uses it, including a product name or a required legal phrase. Say whose words they are. Do not simplify a legal sentence by changing its meaning.
