# Use Real Content

Placeholder text hides the design problems that real content creates. People judge a product by what it says.

- Use the words users used in discovery and the terms in the glossary. No lorem ipsum, "Button", or "Submit"
- Show the hard content: the longest name, an empty list, a hundred items, a missing value, a translated string that runs longer
- Use fictional but plausible data. Never copy real personal data into an artifact
- Name each action by what it does. "Swap shift with Lan" beats "Confirm"
- Content is proposed until an owner approves it. Legal or policy wording needs that owner
