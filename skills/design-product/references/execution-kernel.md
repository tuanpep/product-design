# Execution kernel

Read once per active context; reload only if changed.

- Establish target package, authorization, current phase, output cap and named handoff. Preserve IDs, accepted decisions and human edits. Do not invent evidence, policy or human approval.
- One phase per run unless this message opens the next. Full/advise alone do not advance. Next/continue/approval or naming the next phase opens it without another discovery/confirmation/level question. Missing facts stay unknown; exclude unsafe behavior. Load [discovery policy](discovery-interview.md) for new briefs, interviews, advances or changed core premises.
- **Understand:** decision, needs, context in `product-design.md`. **Shape:** alternatives, experience and service copy in the brief plus `test-plan.md` for evaluation. **Specify:** one bounded SRS in `build-spec.md` with requirements matrix and verification cases in the same plan, when Full and phase open. Use [the essential template selection](documentero-templates.md); no screens, mockups, diagrams or technical schemas from this plugin.
- Levels cap outputs: `understand` discovery only; `design-documents` Shape without screens; `full` permits Specify. Default unnamed Shape after advance is design-documents. Omit artifacts rather than raising the cap. Load [output standard](output-standard.md) only for applicable headers.
- Protection/inclusion, recovery, boundary coverage, single ownership and testable outcomes remain even without a leaf read. Load principle leaves only for conflict/citation. A reversible default cannot close a blocking safety/policy/feasibility question.
- Standalone review is read-only. Authorized repairs change the owning definition first and recheck dependents. Coherence, evidence confidence and readiness are separate; none is permission to build.
- Write authorized files once; return paths and concise findings. The owner controls interviews, phase authorization and integration. When delegating, follow [orchestration](orchestration.md); do small coupled work inline when the host allows.

For disputed scope use [specialist execution](specialist-execution.md). Load only the active pack from [phase routing](phase-routing.md).
