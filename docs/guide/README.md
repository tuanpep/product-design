# The product design guide

`/design-product` is the front door. You describe the idea. It picks a playbook, reads the principle skills the decision needs, and calls the other skills as the steps need them. Say `advise` when you want a suggested solution and design without being asked to decide.

1. [Start](01-start.md). Install the plugin and run the first prompt.
2. [Route work through `/design-product`](02-design-product.md). A new idea and a revision take different playbooks.
3. [Steer with principle names](03-principles.md). The eighteen names that redirect a design choice.
4. [Check output quality](04-output-standard.md). Validate a design package and review it.
5. [Evaluate the skills](05-skill-evaluations.md). Record isolated host trials, edit scope, semantic findings and measured costs without confusing structural checks with behavioral evidence.
6. [Orchestration and tokens](06-orchestration-and-tokens.md). Configure bounded workers, read-only enforcement, phase loading and opt-in attributed usage with explicit coverage limits.
7. [Quick connected-screen mockups](07-quick-mockups.md). Create standalone Draw.io UI sketches with a compact source and reusable renderer, outside the complete-handoff workflow.

Read the pages in order the first time. After that, each page stands alone.
